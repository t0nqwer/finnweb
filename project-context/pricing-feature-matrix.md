# FinnWeb Pricing Feature Matrix (Canonical)

Updated: 2026-04-18
Status: Official baseline for package copy/features in workspace documentation and user-facing pricing content.

## Plan Positioning

- FREE: เหมาะสำหรับทดลองเล่น/นามบัตร
- BASIC: เหมาะสำหรับเริ่มต้นมีหน้าร้าน
- BUSINESS: เหมาะสำหรับสายขาย/ยิง Ads (แนะนำ)
- PRO: เหมาะสำหรับเอเจนซี่/บริษัทใหญ่

## Feature Matrix

| Feature        | FREE (฿0)        | BASIC (฿250/ด.)       | BUSINESS (฿490/ด.) | PRO (฿990/ด.)        |
| -------------- | ---------------- | --------------------- | ------------------ | -------------------- |
| จำนวนเว็บไซต์  | 1 เว็บไซต์       | 1 เว็บไซต์            | 3 เว็บไซต์         | 10 เว็บไซต์          |
| หน้า/เว็บไซต์  | 1 หน้า           | 3 หน้า                | 10 หน้า            | 50 หน้า              |
| Sections/หน้า  | 10 Sections      | 20 Sections           | 50 Sections        | 100 Sections         |
| Ecommerce      | -                | 3 สินค้า (Basic Cart) | 50 สินค้า + สต็อก  | 1,000 สินค้า + สต็อก |
| Blog / News    | -                | -                     | 50 โพสต์           | 1,000 โพสต์          |
| Custom Domain  | -                | รองรับ                | รองรับ             | รองรับ               |
| Tracking/Pixel | -                | -                     | Full Integration   | Full + Custom Code   |
| Analytics      | -                | -                     | Dashboard ละเอียด  | Advanced Reports     |
| LINE OA        | จำกัด 5 ครั้ง/ด. | จำกัด 50 ครั้ง/ด.     | ไม่จำกัด           | ไม่จำกัด             |
| Support        | Help Center      | Standard Support      | Priority Support   | Exclusive Advisor    |
| ข้อเสนอพิเศษ   | -                | ทดลองฟรี 7 วัน        | ทดลองฟรี 7 วัน     | Custom Code / API    |

## Notes

- Plan naming must remain canonical: Free / Basic / Business / Pro.
- Business remains the recommended public tier for Thai SME launch.
- If implementation constraints differ from this matrix, raise a decision update before changing user-facing copy.
